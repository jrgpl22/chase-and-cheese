# 🧀 CHASE & CHEESE

A competitive local 2-player PC game built in **GameMaker Studio**, developed for the Young Creatives Challenge.

Players take on the roles of a **Mouse** and a **Cat** in a fast-paced battle — one collects cheese while the other tries to stop them before time runs out.

---

## 🎮 Gameplay

- 🐭 Mouse vs Cat — local 2-player
- 🧀 Cheese teleports every 15 seconds
- ⌨️ WASD vs Arrow Keys
- ⏱️ 80-second rounds
- 🏆 Best-of-three matches

---

## 🎯 Objective

**Mouse**
- Collect 10 cheese points
- Survive until the timer hits zero

**Cat**
- Catch the Mouse
- Or stop the Mouse from reaching 10 points before time runs out

---

## 🛠️ Tech Stack

- GameMaker Studio (GML)
- Git / GitHub
- Map Assets by Pixel-Boy and AAA (CC0, https://pixel-boy.itch.io/ninja-adventure-asset-pack)
- UI: Canva
- Sound effects: Pixabay
- Piskel

---

## 🕹️ How to Play

**Download and play (Windows)**
1. Go to the [Releases](../../releases) page
2. Download the latest `.zip`
3. Extract it and run the `.exe`
